# 移动端工作区与工具 App

从 [工作区骨架](direction-workspace.md) 过来：任务以手机为主要使用视口时读。工作区的设计变量、数据规则和自查评审仍按那份文件。

让用户在手机上处理对象、记录或追踪状态的 App 按本文件组织页面；桌面的多栏网格、宽表格和面包屑顶栏不压缩搬进手机。设计变量与交互闭环仍适用。

- **顶部只交代当前任务。** 主屏直接以当前屏标题或核心对象状态开头，不单占一行画品牌顶栏，也不叠装饰性的英文眉题；次要状态并入标题行或摘要。搜索默认是按钮或同行筛选，不放常驻的宽搜索框挤占列表。
- **导航分主次。** 有 2–5 个顶层目的地时用底部标签栏，并给安全区留内边距；详情、筛选和编辑用栈式推进或底部面板，不常驻侧栏。
- **列表先保住判断依据。** 每行只留对象身份和一两个决定是否处理它的指标，数值用 `tabular-nums` 对齐；次要字段进详情，不靠缩小字号塞满一行。
- **主操作够得着。** 主要动作放在屏幕下半部的拇指可达区，可点区域至少 `44×44px`，不被底部标签栏或安全区盖住。
- **输入时也能提交。** 软键盘弹出后，当前输入能滚进可见区域，提交动作留在键盘上方。
- **跨屏保持同一套状态。** 多屏交付统一状态栏、安全区和底栏的高度与选中规则；同一对象的数据、进度和编辑状态前后一致，返回列表后保留原位置与选择。
