# 工作区键盘、焦点与高频反馈

上级入口：[工作区骨架](direction-workspace.md)。这里处理复杂键盘导航、拖拽与高频连续处理，不重定视觉主题，无需额外预读其他交互或动效文件。

## 先设计连续处理，不设计快捷键装饰

先写一条真实序列：`定位对象 → 查看判断依据 → 执行动作 → 看到结果 → 进入下一条`。鼠标和键盘都能完成这条序列，再决定是否增加命令面板；不要先画一个 `⌘K` 角标，再给它找功能。

- **行导航**：列表或表格有明确当前行，方向键或产品约定的按键移动时不意外执行动作；当前行始终可见，长列表自动滚到视口内。
- **选择与动作**：当前、键盘焦点和批量勾选是不同状态。队列需要持续展示详情时可以默认定位首条，但不自动勾选批量对象，不因此执行动作；键盘、右键和可见按钮调用同一组动作。
- **命令面板**：动作多、对象明确且用户会重复使用时再加。搜索覆盖对象名称和动作，结果说明作用对象与必要后果；选择动作后焦点回到原对象，不能只有一个没有后续结果的弹层。
- **快捷键可发现**：在菜单、工具提示或搜索框附近显示真实可用的按键；`Cmd/Ctrl` 按平台适配。输入框、文本编辑和浮层打开时不抢字符键，单键快捷键不能代替可访问名称。

## 拖拽

- **拖拽保留来源和落点。** 当前对象稍微抬升，原位置保留占位，合法落点与插入位置清楚，放下后对象和计数一起更新；取消后回到原位置。拖拽不是唯一入口，键盘与触屏有等价的“移动到…”动作。

## 焦点与上下文是同一个问题

| 场景 | 应该保留什么 |
| --- | --- |
| 打开详情或抽屉 | 触发对象、列表筛选、滚动位置和打开前焦点 |
| 关闭详情或抽屉 | 焦点回到原行或原触发按钮；对象已消失时落到合理的相邻对象并说明变化 |
| 处理完一条 | 当前行显示结果，计数同步；下一条进入当前位置，不把视线送回列表顶部 |
| 打开命令面板或浮层 | 焦点进入可操作内容，关闭后回到触发处；Esc 不额外丢未提交的页面状态 |

用键盘完整走一遍：进入列表、打开对象、执行动作、关闭详情、处理下一条；动作支持撤销时，再反向撤销一次。焦点突然回到页面顶部、当前对象不可见或每步都要重新定位，就不算高频流程完成。

## 高频反馈

- **权限范围。** 权限不足时说明当前可见范围。
- **部分成功保留失败项。** 区分成功与失败对象，保留失败项及原因，重试只作用于未成功项。

## 动效以连续和安静为先

这一节覆盖 [动效](motion.md) 的三处必做、物理材质推导、选中滑块、悬停上浮、边界回弹和整页转场默认值；需要核对流畅度或减少动态效果时按需参考 [动效](motion.md) 的“体验与性能”与“检查动效”。先沿用项目已有的反馈与过渡，不为达成动效数量添加表现。

| 变化 | 工作区做法 |
| --- | --- |
| 按下、提交与完成 | 立即反馈状态，保持控件尺寸；结果真实返回后才显示成功，业务状态不等待动画 |
| Tab、筛选或切换当前对象 | 当前位置及时更新；分段 Tab 的选中滑块或底部指示线切换时平滑移动 |
| 打开或关闭详情 | 过渡说明面板与触发对象的关系，列表位置保持；关闭后焦点回到触发处 |
| 刷新、加载或错误重试 | 保留已有可用内容和输入，局部表达更新；不让整页重新入场 |
| 首次进入 | 工作内容可以直接稳定呈现，不强制分块出场 |

过渡只改变受影响的区域；高频变化短促、可打断，快速切换以后到达最后一次操作的正确状态。新旧内容不交叠到难以阅读，不为了丝滑让不同数据范围的旧内容冒充新结果。减少动态效果时直接到位，功能与信息完整保留。

实际操作一次正向、返回与快速连续切换，核对对象、焦点、输入和滚动位置；静态截图只能验证终态，不能证明正常速度的手感。
