# 重设计

返回 [主入口的选择范围](../SKILL.md)。重设计是改变现有界面的视觉方向，不自动授权改变业务流程，也不自动开启多方向探索。

先按 [存量项目](existing-project.md) 完成现状盘点、规范体检和基线截图，再写一张范围卡：

| 范围 | 锁定或允许改变 |
| --- | --- |
| 品牌资产 | 默认锁定；用户明确允许更换时才改 |
| 功能与业务结果 | 未授权时锁定 |
| 业务入口、步骤与流程 | 未授权时锁定；需要改流程时另走 [存量流程](existing-project-workflow.md) |
| 页面结构与全局导航 | 写清保留和可改的部分，不把视觉重做等同于信息架构重做 |
| 视觉语言与组件样式 | 按用户允许的重设计范围决定 |

范围不确定且会改变核心结果时先确认。之后按 [主入口的选择领域](../SKILL.md#选择领域) 读取领域入口，形成它要求的方案产物；仅在领域要求时再按 [设计方向](design-direction.md) 形成方向卡，默认确定一个对外方向并深化；只有用户明确要求比较时，才叠加 [显式探索](task-explore.md)。需要用生图探索版式张力、1x 工作区比例或长落地页节奏时，按 [生图激发创意与提示词](image-ideation.md) 先生成效果图并采样色板，再转化为响应式代码。内部概念、草图和素材候选按领域规则生成和筛选。

新规范先落到共享设计变量和组件，在一个代表性页面上完成并检查，再逐页迁移，不一次重写所有页面。叙事和内容浏览页面按 [方向贯穿整页](direction-whole-page.md) 延续选定方向；产品工作区按 [工作区骨架](direction-workspace.md) 的“设计变量与组件”迁移。选择前的概念把关与做完后的评分，均按 [存量项目](existing-project.md) 的“各类改动怎样评审”执行重塑一行，不因默认单方向降低真实画面、交互和做完后的独立评审要求。
