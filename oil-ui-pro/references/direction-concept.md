# 说服型页面的概念

落地页、品牌页、发布页、展览页用这份文件，在拆标杆之前开始读。它管五件事：概念从哪来，怎样变成三个方向，没有人挑选时怎样自己选，选定后怎样带到首屏以下，整页的图怎样做成一套。骨架见 [说服型骨架](direction-persuasion.md)，其余流程见 [设计方向](design-direction.md)。

说服型页面先有概念：北极星和生成引擎从选中的概念推出，不另起一个；标题随概念先定，骨架在它之后选，其余文案在骨架之后写。

## 概念是什么

一句话：把这个产品最想让人记住的主张，说成一个具体的画面。标题和主视觉从这一句里一起推出，讲的是同一件事；左边喊一句通用卖点、旁边摆一张普通的产品截图，两边各说各的，不算概念。

动手想概念前，先在笔记里**盘点 6–10 件只属于这个主体的具体事物**：如果是数字产品或工具，写下它真正读写的对象、核心操作前后的状态变化、关键指标或用户原本手边的旧工具；如果是实体、空间或文化品牌，写下它的名字本意、街区与场所特征、题面里的硬数字和限制（批次数、周期、规格）、原材料色泽，以及它世界里的真实凭据（吊牌、传票、铭牌、联单、图纸）。概念的画面、版块的载体和后文的找图关键词，都从这份清单里取。

写完概念后用一句填空做**同行替换检验**：
> 在这页上，**【盘点清单里的一件具体事物】** 变成了 **【首屏和整页的核心视觉、版块载体或交互装置】**。

三条检验，有一条不过就换一个概念，不靠加说明补救：

- 标题和主视觉分开看，各自不完整。主视觉就是文字本身的方向，这一条不适用。
- 合起来一读就懂。
- **换到同品类另一家产品上不成立**：把隔壁同行的名字代进上面的填空句，如果句子依然成立（例如拿通用趋势图代表任何数据分析工具、拿普通木纹代表任何木工坊），说明想到的只是品类套话，回到盘点清单重选。

主视觉可以直接把产品处理的对象或交付的结果做成画面，也可以借一个受众一眼认得、和产品主张道理相通的事物来表达，首屏不必放完整的产品界面。借来的事物和它的画法，来源就是这句概念，这就是 [设计方向](design-direction.md) 要求说得出的来源。概念只管标题、主视觉和各区块的画面；功能名、按钮、导航和价格用产品本身的说法。

**让容器和交互也顺着概念长出来。** 选定概念后，别让概念只停在首屏的一张图上，到了下面又退回成千篇一律的通用网页线框：
1. **通透画布配一两处点睛载体**：整页大部版面让主视觉、大字和核心内容直接排在通透的底色画布上，靠留白呼吸，不把每一屏都封进有底色和边框的卡片盒子里。只在最核心的 **1–2 处节点**做成呼应概念的专属载体——数字产品或工具可做成可直接试用的微缩工作台、实时终端或对比面板；实体、展览或品牌题材可做成对应的工坊吊牌、标本卡或预留联单，不跨题材硬套。
2. **一处点题的真交互**：设计一处由概念直接推出来的可操作装置（如切换规格与参数时，画面、数据、价格或声音当场联动），用业务真实数据驱动，支持手机单手操作。

## 概念交给子 Agent 出

主 Agent 看过标杆以后，自己起的方向会回到标杆的首屏上，换几次颜色和字体也一样。同一个模型换一个出发点、不看标杆，给出的想法会远得多。所以概念由全新的子 Agent 出，主 Agent 负责挑。

派 5 个全新的子 Agent，可以和拆标杆同时进行。每个只给产品、受众、和同类的不同，以及一个出发角度；不给标杆截图，不给主 Agent 已有的想法，不给其他子 Agent 的结果。提示词：

```text
你在给一个产品的落地页想首屏概念。只根据下面的信息想，不查同类产品，不读文件。

产品：<它是什么，替谁做什么，一两句>
受众：<是谁，来这页之前的处境>
和同类的不同：<一到三条>
出发角度：<下面五条之一的原文>

交回 3 个彼此不同的概念，每个写四行：
1. 概念：一句话，把产品的主张说成一个画面。
2. 标题：页面上的原文，不超过两行。
3. 主视觉：首屏最大的那样东西是什么、长什么样，写到能照着画出来。
4. 只属于这个产品的理由：换到同类另一家为什么不成立。

不写版式、配色、字体和页面的其余部分。
```

五个出发角度，一个子 Agent 一条：

- **受众的处境**：从受众来这页之前卡在哪、担心什么、想变成什么样出发，不从产品功能出发。
- **借一样东西**：找一个受众一眼认得、和产品主张道理相通的事物，用它来说。首屏不出现产品界面。
- **说反话**：这个品类人人都在说的那句话是什么，从它的反面或它没说的那一半出发。
- **一句话加一张图**：首屏只有一句话和一张图，图不是产品界面。
- **另一个领域**：这个主张放到一个和软件无关的领域里会怎样被表现，借那个领域的表现形式。

宿主不能派子 Agent 时，主 Agent 在取标杆画面之前，按这五个角度各写 3 个概念，写完再去拆标杆。后面几处要子 Agent 看图或出画面的，主 Agent 按同样的问题自己做，交付时写明没有隔离。

## 挑三个方向

1. **先删。** 彼此重复的；标题换个产品名也成立的；和拆过的标杆首屏是同一个意思的。
2. **再验。** 剩下的逐个过三条检验。
3. **选三个彼此最远的。** 三个概念各不相同，不是同一句话的三种排法；至少一个的主视觉是一张图，画的不是产品界面；以产品实样为主视觉的至多一个。任务只要一个方向时，选检验里最站得住的那一个。
4. **各写各的。** 标题、副标题和主视觉每个方向各写各的；产品事实和示例数据（名称、功能、价格）共用。副标题用一句平实的话说清产品是什么。
5. **再选骨架。** 每个概念从 [说服型骨架](direction-persuasion.md) 的表里选骨架，同一轮互不相同。
6. **写进方向卡。** 方向卡加一栏“概念”：这句概念、来自哪个角度、三条检验的结果。对比页 manifest 的 `concept` 仍填北极星，概念这一句写进 `traits`。

用文字问用户时，每个方向写上标题原文和主视觉是什么。做成首屏时，以图为主视觉的方向各出 2–4 张主图候选，候选之间在主体、构图和画法上拉开，逐张放进首屏后挑一张，不用色块占位；出图前先读 [素材](media.md) 的“写提示词”。这里的截图和下一节派的子 Agent，不算首屏那一轮说的取证和评审。

标杆只提供基线：这页要回答的问题和主动作的位置。标杆首屏的构图不算基线，算套路。

## 自己选定

用户说了“你定”或无人值守时：

1. 把三张首屏截图和标杆的首屏截图（有的话）一起交给一个全新的子 Agent，不给方向名和说明，问三件事：哪一张遮住品牌名会被当成标杆里的某一家；每一张看三秒以后还记得什么；哪一张最让人想往下看，为什么。
2. 先去掉会被当成标杆的，再从剩下的里选“还记得的东西”最具体的那一个。
3. 只要副标题和第二屏能把产品说清楚，首屏不必把所有功能解释完；优先选看三秒还能记住具体画面的那一个。
4. 写明选了哪个、子 Agent 怎么说、另外两个为什么落选。

请用户挑选时，推荐理由先写这两条：会不会被当成标杆，让人记住的是什么。还没有首屏、只有文字时，主 Agent 自己按这两条判断。

## 把概念带到首屏以下

方向选定后、做完整页面之前做这一步。主 Agent 自己往下排，会回到这个品类的通用区块，概念只剩首尾两处。所以首屏以下每一屏长什么样，同样先让子 Agent 出。

选定的方向以图为主视觉时，先把主图定稿（“整页的图做成一套”第 1 步），后面都以定稿的首屏为准。

再列出这页还要回答的问题，按产品事实写，例如它怎么用、有什么不同、有什么现成的、多少钱、现在做什么。派 3 个全新的子 Agent，每个给首屏的截图、概念、标题、这份问题清单和一个出发角度；不给标杆截图，不给主 Agent 打算怎么排，也不说每个问题通常用什么区块回答。提示词：

```text
一个落地页的首屏已经定了，附图是它的截图。
概念：<那一句概念>
标题：<页面上的原文>
这页还要回答这些问题：<问题清单>
出发角度：<下面三条之一的原文>

为这些问题设计首屏以下的几屏，可以合并或调换顺序，让每一屏是首屏那个想法的下一句。每屏写三行：
1. 小标题：页面上的原文。
2. 画面：这一屏最大的那样东西是什么、长什么样、和首屏的图是什么关系，写到能照着画出来。
3. 产品事实落在哪：数字、功能、价格这些必须出现的内容，放在这个画面的什么位置。

不要退回“三列小图标配标题”的通用模板，也不要放和概念无关的通用示例截图。哪一屏确实只需要文字、对比表或几张具体的特性卡，直接说。
```

三个出发角度，一个子 Agent 一条：

- **同一样东西往下走**：首屏的那样东西在每一屏换一个时刻、角度或局部。
- **它的同伴**：每一屏一样新的东西，和首屏的图同属一套、同一种画法。
- **一个连续的变化**：从首屏到结尾是同一件事的经过，每一屏是其中一步。

收齐以后写画面表，再开始做整页。从三份里挑一份，或逐屏挑最好的拼成一份，每屏一行：回答哪个问题、小标题、画面、图从哪来、产品事实落在哪。它就是方向卡里“页面结构”和“各区块的形式”两栏；滚动分镜照常写在“动效”一栏。

- 选定的方向以图为主视觉时，首屏以下哪几屏要配图，按画面表的实际需要定，不为凑数给只需要文字或表格的区块硬加图。要配图的屏做新图，不用主图的裁切或缩放充数；主图的局部至多用在一屏，结尾可以再用一次主图。按“让一张画当舞台”做的方向照那一节走。
- 价格、功能对比这类必须是表的，表照常做，表头、底或分隔取自同一套素材。
- 产品实样占其中一屏，放进这套画面里，示例内容从概念里取，不另起一个题材。

整页做完后的逐屏对照按 [方向贯穿整页](direction-whole-page.md) 做，对照的是这张画面表。送评审时，把这句概念摘成一句写进交接的约束。

## 整页的图做成一套

选定的方向以图为主视觉时，图决定页面的上限。

1. **主图定稿。** 做首屏时出的候选如果已经立得住，直接选定并精修；还不够到位再补几张，算上之前出的总数不超过 8–12 张。沿用选定首屏的主体和画法，在姿态、构图和细节上拉开，不是同一句提示词出多张。逐张放进真实首屏，拼成一张并排图一起看，按三条挑：和标题合起来是不是一个意思；文字压不压得住；缩到一半大小还认不认得出主体。写下选了哪张，其余各因为什么落选。选中的用高画质重出或精修，透明底在这一步做。
2. **其余的图从主图改出来。** 画面表里每一张新图，都拿定稿的主图当参考图来生成，提示词写明沿用它的材质、光向、视角和色板，换的是主体、时刻或角度。宿主不能传参考图时，先把主图的画法写成一段风格说明，原样放进每一条提示词。每张先出 1–3 张候选，放进它所在的那一屏挑定。
3. **需要材质或底纹时，再出一两张这一套的。** 用在卡片底、表头和分隔上，页面不留和这套图无关的色块；页面本身是干净纯色底时不硬加。已有合适的同套现成素材可以直接用。
4. **拼素材并排图，交给子 Agent 看。** 主图、画面表里的新图和用到的材质，拼成一张图存进任务目录。派一个全新的子 Agent，只给这张图，问三件事：哪一张不像同一套；哪一张像通用素材库里的图；哪一张缩小以后认不出主体。被点到的重做。
5. **放进页面以后接起来。** 逐张对照 [素材](media.md) 的“让图和页面接成一体”：主视觉和跨区块的大图不要关在小卡片里，按画面做背景融合、透明底跨界、文字压图，或者需要指明图里位置时用代码画线接出去。
