# 内容浏览页面骨架

画廊、商店、信息流、文档站、作品集等让人浏览、挑选内容的页面，首屏就是第一排内容本身（整体设计方向流程见 [设计方向](design-direction.md)）。用户在页面上主要是处理、比较或编辑对象时，这一页属于产品工作区，回到入口按产品工作区处理。

页头占几行、首屏放什么的底线见 [设计方向](design-direction.md) 的“定首屏与工作区骨架”。这类页面没有首屏海报，内容本身就是主角。先写两行：

- **内容对象**：用户来看、来挑的是什么，一眼认出它靠哪两三个属性。
- **来的频率**：常来翻看的老用户，还是偶尔从搜索或分享链接进来的访客。它决定密度和导航要多显眼。

**浏览与挑选用画廊、货架或信息流。** 内容铺满首屏，缩略图的比例就是版式；筛选和排序贴着内容顶部，占一行；点开时在原地展开或用浮层，关上回到原来的位置。

**文字索引是画廊的一种变体。** 对象靠名字、类型和年份就能区分时，例如作品集、案例、目的地、文章，十到几十项，首屏可以先放一张文字索引：每行是名字加两三个属性，日期和编号用等宽数字。悬停或聚焦某一行时，它的图出现在列表旁的固定位置，不跟着鼠标跑，也不挡住下一行。再给一个“列表 / 图片”切换，切过去仍停在同一个对象上。触屏没有悬停，点一下展开这一行的缩略图。图片本身就是卖点的内容，例如摄影和商品，仍然图片先行。

**对象的样子就是主视觉。** 先设计一个对象在卡片或列表行上的样子：图和名称怎样排，最重要的属性放在哪，长名字怎么收，空值怎么显示，悬停和选中长什么样。

**密度按频率定。** 常来翻看的目录可以更密；偶尔来一次的访客，点击区域 44px 以上，一屏只要求一个决定。密度要在截图上数出来：首屏能看到几个完整对象。

**大胆放在内容上。** 页面标题和品牌区保持小：一行，和区域标题同级或略大。放超大页面标题、通栏口号，或者用一整块深色卡片装“下一步”动作，都是把落地页的手法搬错了地方，占掉的是用户来看的内容。

**顶栏放什么。** 顶部第一行是每天看得最多的位置。先问用户在这一屏需不需要靠品牌认路，需要才放品牌标识：

- **App**：用户点图标进来，已经知道在哪个 App。一级页顶部放当前屏名称（可以用大标题）、当前对象，或最常看的状态，例如余额、连胜、剩余次数；二级页放返回和标题。品牌字标通常不出现在顶部。品牌本身就是入口的信息流首页、启动页、登录与引导页可以放。
- **网页**：落地页、官网、品牌页、文档站、商店这类访客可能从搜索或分享链接直接落地的页面，左上角放标识，告诉他在哪个站、点它回首页，尺寸和导航同级，不放大成第二个主视觉。
- 品牌行和页面标题不在同一处上下叠成两层头部；两样都需要时，合进同一行，或分到侧栏和主区。

画面里的实物铭牌、包装和招牌属于内容，不算顶栏的品牌行。品牌方有明确要求，或方向本身需要字标出现在每一屏时可以放，在方向卡里写出理由。

多个方向时，使用频率已经决定的密度可以保持一致，重点在页面骨架、对象的样子和导航方式三项上拉开，任意两个方向至多一项相同。这三项是在通用差异检验之外再比，不是替代：同样需要各自的色彩身份和字体性格，不能三个方向都是系统黑体加一种强调色，只换了布局。基于选定方向派生版式时，字体、配色和密度都照选定的方向，只比页面骨架、对象的样子和导航方式。方向卡里的“首屏骨架”一栏，填页面骨架和对象的样子。
