# 极空间 Z4 连接

使用随附脚本完成连接，无需依赖 MusicCenter 项目或安装第三方 Python 包。运行环境为当前 Mac、Python 3.9+，以及系统自带的 security、expect、ssh 和 NetFS。Mac 需要能访问家庭局域网。

## 连接入口

以下路径是当前安装位置；若 skill 被移动，改用实际 skill 目录下的脚本。

```sh
# 确认 SMB 已挂载；未挂载时主动挂载；成功只输出挂载路径。
python3 /Users/ben/.agents/skills/z4-connect/scripts/z4_connect.py smb

# 从钥匙串读取账号密码，执行远程命令，输出远程结果并返回远程退出码。
python3 /Users/ben/.agents/skills/z4-connect/scripts/z4_connect.py ssh 'hostname; id'

# 仅在当前任务需要管理员权限时提权。
python3 /Users/ben/.agents/skills/z4-connect/scripts/z4_connect.py ssh --sudo 'id -u'
```

SSH 默认命令为 `id`；`--timeout 120` 可调整认证和命令各阶段的等待秒数。每次调用是一条非交互命令，不支持交互 shell 或通过标准输入传输文件。需要复杂命令时用本地脚本构造字符串并作为单独参数传入，避免多层 shell 展开。

## SMB 文件访问

连接前运行 `smb` 入口，退出码为 0 后再访问输出的路径。脚本核对 SMB 来源、账号、共享和真实挂载点；仅检查目录存在不足以确认 NAS 已挂载。

- 当前设备：`Z4-9S2X`，地址 `192.168.5.28`。
- 当前共享：`135XXXX9330`，挂载点 `/Volumes/135XXXX9330`。共享名与完整管理员账号不同。
- 已正确挂载时直接复用，不读取密码、不重复挂载。
- 未挂载时通过 NetFS 和钥匙串凭据主动挂载，最长等待 45 秒，然后重新核对挂载结果。
- 路径被本地目录、符号链接或其他共享占用时停止；保留原路径供排查。自动生成的 `-1` 路径不算成功。

上传或创建文件仍按用户当前任务确定目录和覆盖规则；连接成功本身不授权修改 NAS 数据。长期运行的脚本应在每批写入前再次核对挂载，并检查目标目录解析后仍处于该挂载点内，防止断线后写到本地或越过目录链接。

## SSH 和凭据

SSH 地址为 `192.168.5.28:10000`。账号从钥匙串服务 `codex.nas.z4.ssh` 的 `acct` 元数据读取，密码从同一条目读取；SMB 复用该凭据。此处的“密钥”目前实际是管理员密码，未配置 SSH 私钥。不要擅自生成密钥或修改 NAS 的 SSH 设置。

脚本把密码留在认证进程内存中，不写入 skill、配置、命令行参数或日志。保持认证调试输出关闭；不要单独运行带 `-w` 的钥匙串读取命令，也不要输出进程内存中的凭据。

SSH 使用 `StrictHostKeyChecking=yes`，信任当前 Mac 的 known_hosts。历史首次连接使用了 accept-new，尚未通过设备控制台独立核验指纹。遇到未知或变化的主机密钥，先核验设备指纹，再更新记录；不要关闭检查或自动删除记录。

普通文件上传优先使用 SMB。此设备的 SSH 管理员账号曾无法直接写入共享目录；SSH 用于远程查询和确有需要的管理员操作。极音乐 Web 会话属于独立鉴权，不包含在本 skill 中。

## 失败处理与凭据维护

以非零退出码作为停止条件；挂载失败时不要继续写文件。网络恢复后可重新调用，认证失败时先修正原因，避免循环尝试密码。报告连接方式、成功与否及非敏感错误即可。

- 钥匙串不可用：检查当前 Mac 用户、登录钥匙串解锁状态，以及 security 对条目的访问授权。
- SMB 失败或超时：检查局域网、NAS 在线状态、SMB 服务和共享权限。
- SSH 失败：检查端口 10000、已记录的主机密钥及管理员凭据。远程命令返回非零时保留其退出码。
- sudo 失败：检查管理员权限；仅在任务需要时使用 `--sudo`。

需要更新密码时，让用户在 Mac 终端的 zsh 中执行：

```zsh
read "z4_account?极空间管理员用户名："
security add-generic-password -U -a "$z4_account" -s codex.nas.z4.ssh -w
unset z4_account
```

`-w` 位于末尾且后面没有密码，系统会提示输入。每个服务保留当前使用的一条账号记录；脚本不会自行修改凭据。

修改连接脚本后，运行 `python3 -B -m unittest discover -s <skill目录>/tests -v`。这些离线检查模拟挂载、钥匙串和 SSH，不改动真实连接。
